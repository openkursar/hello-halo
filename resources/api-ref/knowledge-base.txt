## knowledge-base — document collections agents can search
covers: create and delete collections, bind them to a space, import and remove
        documents, indexing progress and status
not here:
  ordinary files in a space -> workspace
  digital humans that read a collection -> digital-human

operations on this page:
  POST   /api/tlon                                                   Create a knowledge collection
  GET    /api/tlon                                                   List all knowledge collections
  GET    /api/tlon/<kbId>                                            Get one knowledge collection by id
  PUT    /api/tlon/<kbId>                                            Rename or edit a collection's description/status
  DELETE /api/tlon/<kbId>                                            Delete a knowledge collection and all its data   !! destructive - narrower: POST /api/tlon/<kbId>/remove-raw
  POST   /api/tlon/<kbId>/bind-app                                   Bind a knowledge collection so a digital human can read it
  POST   /api/tlon/<kbId>/bind-space                                 Bind a knowledge collection to a space
  POST   /api/tlon/<kbId>/clear-relearn                              Wipe extracted text and re-index a collection from scratch
  POST   /api/tlon/<kbId>/files                                      Add existing server-local files to a collection by absolute path
  GET    /api/tlon/<kbId>/index                                      Read a collection's document map (index.md)
  POST   /api/tlon/<kbId>/ingest                                     Start indexing a collection's documents (fire-and-forget)
  GET    /api/tlon/<kbId>/ingest-status                              Get the current indexing progress for a collection
  POST   /api/tlon/<kbId>/linked-dirs                                Watch a server-local directory as a live document source
  DELETE /api/tlon/<kbId>/linked-dirs/<linkId>                       Stop watching a linked directory
  GET    /api/tlon/<kbId>/raw                                        List the raw source files added to a collection
  POST   /api/tlon/<kbId>/remove-raw                                 Remove one document (raw source file) from a collection   !! destructive
  POST   /api/tlon/<kbId>/unbind-app                                 Unbind a knowledge collection from a digital human
  POST   /api/tlon/<kbId>/unbind-space                               Unbind a knowledge collection from a space
  GET    /api/tlon/for-space/$HALO_SPACE_ID                          List knowledge collections bound to a space (or the default one)
  POST   /api/tlon/set-default                                       Set (or clear) the collection new conversations auto-load

POST   /api/tlon                                                   Create a knowledge collection
     curl -sX POST "$HALO_API_URL/api/tlon" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"name":"Product Docs"}'
     # body: {"name":"Product Docs"}
     # out: {success:true,data:{id,name,icon,description,status:"active",createdAt,updatedAt,path,linkedDirs:[],spaceIds:[],appIds:[],stats:{...}}}
     # note: Optional fields: icon, description, linkedDirs (array of {path,label}).

GET    /api/tlon                                                   List all knowledge collections
     curl -s "$HALO_API_URL/api/tlon" -H "Authorization: Bearer $HALO_API_TOKEN" | head -c 4000
     # out: {success:true,data:[{id,name,icon,description,status,spaceIds,appIds,stats,isDefault?,...}]}

GET    /api/tlon/<kbId>                                            Get one knowledge collection by id
     curl -s "$HALO_API_URL/api/tlon/<kbId>" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {success:true,data:{id,name,icon,description,status,linkedDirs,spaceIds,appIds,stats,...}} or {success:false,error:"Knowledge base not found"}

PUT    /api/tlon/<kbId>                                            Rename or edit a collection's description/status
     # note: reversible — can be undone or corrected afterward.
     curl -sX PUT "$HALO_API_URL/api/tlon/<kbId>" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"name":"New name"}'
     # body: {"name":"New name"}
     # out: {success:true,data:<updated entry>} or {success:false,error:"Knowledge base not found"}
     # note: All fields optional: name, icon, description, status ("active"|"paused"|"error").

DELETE /api/tlon/<kbId>                                            Delete a knowledge collection and all its data
     !! DESTRUCTIVE: cannot be undone. Confirm with the user in plain language before running this.
     !! If the user meant something smaller, use POST /api/tlon/<kbId>/remove-raw instead.
     curl -sX DELETE "$HALO_API_URL/api/tlon/<kbId>" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {success:true,data:<deletion result>}
     # note: Permanently deletes the collection's entire folder — original source files, extracted text, and the index. Not just the registry entry. If the user only meant to remove one document, use remove-raw instead.

POST   /api/tlon/<kbId>/bind-app                                   Bind a knowledge collection so a digital human can read it
     # note: reversible — can be undone or corrected afterward.
     curl -sX POST "$HALO_API_URL/api/tlon/<kbId>/bind-app" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"appId":"<appId — a uuid from GET /api/apps>"}'
     # body: {"appId":"<appId — a uuid from GET /api/apps>"}
     # out: {success:true,data:<updated entry>}
     # err: 400 if appId is missing.

POST   /api/tlon/<kbId>/bind-space                                 Bind a knowledge collection to a space

     curl -sX POST "$HALO_API_URL/api/tlon/<kbId>/bind-space" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \

     # body: {"spaceId":"<spaceId — a uuid from GET /api/spaces>"}
     # out: {success:true,data:<updated entry>}
     # err: 400 if spaceId is missing.

POST   /api/tlon/<kbId>/clear-relearn                              Wipe extracted text and re-index a collection from scratch
     # note: reversible — can be undone or corrected afterward.
     curl -sX POST "$HALO_API_URL/api/tlon/<kbId>/clear-relearn" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {success:true,data:true} or {success:false,error:"Learning is already in progress"}
     # note: Use when documents were updated in place and stale extracted text needs replacing. Only clears derived/regeneratable data (extracted text, index) — original source files are untouched and text is rebuilt automatically.

POST   /api/tlon/<kbId>/files                                      Add existing server-local files to a collection by absolute path
     curl -sX POST "$HALO_API_URL/api/tlon/<kbId>/files" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"filePaths":["/absolute/path/to/file.pdf"]}'
     # body: {"filePaths":["/absolute/path/to/file.pdf"]}
     # out: {success:true,data:{added:string[],rejected:string[]}}
     # err: 400 if filePaths is missing or empty. Files are copied in, not linked — see linked-dirs for live-watched folders.

GET    /api/tlon/<kbId>/index                                      Read a collection's document map (index.md)
     curl -s "$HALO_API_URL/api/tlon/<kbId>/index" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {success:true,data:string}  — markdown text, empty string if not yet generated

POST   /api/tlon/<kbId>/ingest                                     Start indexing a collection's documents (fire-and-forget)
     curl -sX POST "$HALO_API_URL/api/tlon/<kbId>/ingest" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {success:true,data:true}
     # note: Returns immediately; the indexing job runs in the background. Poll GET /api/tlon/:kbId/ingest-status for progress — back off (2s, then double), do not tight-loop.

GET    /api/tlon/<kbId>/ingest-status                              Get the current indexing progress for a collection
     curl -s "$HALO_API_URL/api/tlon/<kbId>/ingest-status" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {success:true,data:{kbId,total,completed,current?,phase:"idle"|"running"|"done"|"error",error?,errors?:[{file,message}]}}

POST   /api/tlon/<kbId>/linked-dirs                                Watch a server-local directory as a live document source
     curl -sX POST "$HALO_API_URL/api/tlon/<kbId>/linked-dirs" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"path":"/Users/me/Documents/product-docs"}'
     # body: {"path":"/Users/me/Documents/product-docs"}
     # out: {success:true,data:{id,path,label,watching,lastScannedAt?}} on success
     # note: Optional field: label (defaults to path).
     # note: Failure carries a code instead of throwing: TOO_MANY_FILES (data:{count,limit}), DISK_ROOT (cannot watch a filesystem root), FOLDER_TOO_LARGE, PATH_NOT_FOUND, KB_NOT_FOUND.
     # err: 400 if path is missing.

DELETE /api/tlon/<kbId>/linked-dirs/<linkId>                       Stop watching a linked directory
     # note: reversible — can be undone or corrected afterward.
     curl -sX DELETE "$HALO_API_URL/api/tlon/<kbId>/linked-dirs/<linkId>" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {success:true,data:<removal result>}
     # note: Only removes the watch registration — the target folder and its files are untouched, and can be re-linked.

GET    /api/tlon/<kbId>/raw                                        List the raw source files added to a collection
     curl -s "$HALO_API_URL/api/tlon/<kbId>/raw" -H "Authorization: Bearer $HALO_API_TOKEN" | head -c 4000
     # out: {success:true,data:[{name,path,size,learned:boolean,state:"learned"|"pending"|"no-text"|"failed",error?,source:"raw"|"linked",dirLabel?}]}

POST   /api/tlon/<kbId>/remove-raw                                 Remove one document (raw source file) from a collection
     !! DESTRUCTIVE: cannot be undone. Confirm with the user in plain language before running this.
     curl -sX POST "$HALO_API_URL/api/tlon/<kbId>/remove-raw" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"relativePath":"raw/file.pdf"}'
     # body: {"relativePath":"raw/file.pdf"}
     # out: {success:true,data:<removal result>}
     # err: 400 if relativePath is missing. Permanently deletes the copied file from the collection — no trash, no undo.

-----------------------------------------------------------------------
$HALO_API_URL, $HALO_API_TOKEN and $HALO_SPACE_ID are already set in your Bash
  environment. Copy commands as-is; never expand or print those variables.
Replace only <angle-bracket> placeholders. Get real ids from a list call above.
Read the response body and check "success". HTTP 200 alone does not mean it
  worked - many failures return 200 with {"success":false}.
Pipe long responses through `| head -c 4000` so you do not flood your context.
A POST that timed out may still have taken effect. List before you retry.
Waiting on something? Back off (2s, then double), give up after 5 tries and
  tell the user it is still running.
Large or binary files do not go through this API - use Read / Write / Bash.
403 = the endpoint exists but is closed to me in this build. Tell the user to
  do it in the Halo app. Do not tell them Halo cannot do it.
404 with a "code" field = my path is wrong. 404 without one = the id is wrong.
Only call paths listed on this page or in the index. Never write one from
  memory. If this page has left your context, call halo_api_ref again.
Full index of every endpoint: {{API_REF_INDEX_PATH}}/index.txt
  grep -i "<keyword>" {{API_REF_INDEX_PATH}}/index.txt
Not listed here does NOT mean not supported — that is a real, deliverable
  answer, not a failed search. Grep the index before you say "Halo can't do that".
