## workspace — spaces and the files they hold
covers: create, rename, reorder and delete spaces, space settings and working
        directory, browse and read produced files and artifacts
not here:
  documents indexed for retrieval -> knowledge-base
  digital humans living in a space -> digital-human
  stopping a running task -> conversation
  running shell commands in the working directory -> terminal

operations on this page:
  POST   /api/apps/<appId>/move-space                                Move a digital human to a different space (or make it global)
  GET    /api/artifacts/detect-type                                  Detect whether a file is text or binary and how it would be viewed
  POST   /api/artifacts/save                                         Overwrite a file's content
  GET    /api/spaces                                                 List all spaces
  POST   /api/spaces                                                 Create a space
  GET    /api/spaces/$HALO_SPACE_ID                                  Read one space
  PUT    /api/spaces/$HALO_SPACE_ID                                  Rename a space or change its icon
  DELETE /api/spaces/$HALO_SPACE_ID                                  Delete a space and everything inside it   !! destructive
  GET    /api/spaces/$HALO_SPACE_ID/artifacts                        List files and folders in a space
  DELETE /api/spaces/$HALO_SPACE_ID/artifacts                        Move a file or folder to the trash
  POST   /api/spaces/$HALO_SPACE_ID/artifacts/children               Load one folder's children in the file tree
  POST   /api/spaces/$HALO_SPACE_ID/artifacts/file                   Create a new file in a space
  POST   /api/spaces/$HALO_SPACE_ID/artifacts/folder                 Create a new folder in a space
  POST   /api/spaces/$HALO_SPACE_ID/artifacts/move                   Move a file or folder to a different directory
  POST   /api/spaces/$HALO_SPACE_ID/artifacts/reconcile              Resync the file list with what is actually on disk
  POST   /api/spaces/$HALO_SPACE_ID/artifacts/rename                 Rename a file or folder
  GET    /api/spaces/$HALO_SPACE_ID/artifacts/tree                   Get the full lazy-loadable file tree for a space
  POST   /api/spaces/$HALO_SPACE_ID/open                             Get a space working directory path
  GET    /api/spaces/default-path                                    Read the directory new spaces are created under
  PUT    /api/spaces/reorder                                         Set the display order of spaces

POST   /api/apps/<appId>/move-space                                Move a digital human to a different space (or make it global)
     # note: reversible — can be undone or corrected afterward.
     curl -sX POST "$HALO_API_URL/api/apps/<appId>/move-space" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"newSpaceId":"<spaceId — a uuid from GET /api/spaces>"}'
     # body: {"newSpaceId": "<spaceId — a uuid from GET /api/spaces>"}
     # out: {success:true,data:{activationWarning?:string}}
     # note: Send {"newSpaceId": null} to make it global (available in every space). 404 if appId does not exist; 400 if newSpaceId is an empty string.

GET    /api/artifacts/detect-type                                  Detect whether a file is text or binary and how it would be viewed
     curl -s "$HALO_API_URL/api/artifacts/detect-type" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {"success":true,"data":{"isText":true,"canViewInCanvas":true,"contentType":"markdown","mimeType":"text/markdown"}}

POST   /api/artifacts/save                                         Overwrite a file's content
     # note: reversible — can be undone or corrected afterward.
     curl -sX POST "$HALO_API_URL/api/artifacts/save" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"path":"/absolute/path/inside/the/space","content":"new file contents"}'
     # body: {"path":"/absolute/path/inside/the/space","content":"new file contents"}
     # out: {"success":true}
     # note: Fully replaces the file in place — no version history or trash, but you can always overwrite it again to correct a mistake. 403 if path resolves outside an allowed space.

GET    /api/spaces                                                 List all spaces
     curl -s "$HALO_API_URL/api/spaces" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {"success":true,"data":[{"id":"<uuid>","name":"Work","path":"/…"}]}
     # note: Start here when you need a spaceId. $HALO_SPACE_ID is the space this conversation is in.

POST   /api/spaces                                                 Create a space
     curl -sX POST "$HALO_API_URL/api/spaces" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"name":"Product research","icon":"📚"}'
     # body: {"name":"Product research","icon":"📚"}
     # out: {"success":true,"data":{"id":"<uuid>","name":"Product research","path":"/…"}}
     # note: customPath is optional; omit it to create under the default directory.

GET    /api/spaces/$HALO_SPACE_ID                                  Read one space
     curl -s "$HALO_API_URL/api/spaces/$HALO_SPACE_ID" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {"success":true,"data":{"id":"<uuid>","name":"Work","path":"/…"}}

PUT    /api/spaces/$HALO_SPACE_ID                                  Rename a space or change its icon
     # note: reversible — can be undone or corrected afterward.
     curl -sX PUT "$HALO_API_URL/api/spaces/$HALO_SPACE_ID" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"name":"Renamed space"}'
     # body: {"name":"Renamed space"}
     # out: {"success":true,"data":{...updated space}}

DELETE /api/spaces/$HALO_SPACE_ID                                  Delete a space and everything inside it
     !! DESTRUCTIVE: cannot be undone. Confirm with the user in plain language before running this.
     curl -sX DELETE "$HALO_API_URL/api/spaces/$HALO_SPACE_ID" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {"success":true}
     # note: Deletes the space folder recursively, every conversation in it, and every digital human installed in it.
     # note: Nothing is moved to a trash folder and there is no undo.
     # note: Name what will be lost and get the user to agree before running this.

GET    /api/spaces/$HALO_SPACE_ID/artifacts                        List files and folders in a space
     curl -s "$HALO_API_URL/api/spaces/$HALO_SPACE_ID/artifacts" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {"success":true,"data":[{"id":"…","name":"report.md","type":"file","path":"/…","relativePath":"report.md","extension":"md","size":1024}]}
     # note: Optional query param maxDepth (default 2) controls how many directory levels deep to list.

DELETE /api/spaces/$HALO_SPACE_ID/artifacts                        Move a file or folder to the trash
     # note: reversible — can be undone or corrected afterward.
     curl -sX DELETE "$HALO_API_URL/api/spaces/$HALO_SPACE_ID/artifacts" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"path":"/absolute/path/inside/the/space"}'
     # body: {"path":"/absolute/path/inside/the/space"}
     # out: {"success":true}
     # err: 400 if path is missing. Goes to the OS trash (recoverable there), not deleted outright.

POST   /api/spaces/$HALO_SPACE_ID/artifacts/children               Load one folder's children in the file tree
     curl -sX POST "$HALO_API_URL/api/spaces/$HALO_SPACE_ID/artifacts/children" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"dirPath":"/absolute/path/inside/the/space"}'
     # body: {"dirPath":"/absolute/path/inside/the/space"}
     # out: {"success":true,"data":[{"id":"…","name":"index.ts","type":"file"}]}
     # err: 400 if dirPath is missing. 403 if dirPath resolves outside this space's working directory.

POST   /api/spaces/$HALO_SPACE_ID/artifacts/file                   Create a new file in a space
     # note: reversible — can be undone or corrected afterward.
     curl -sX POST "$HALO_API_URL/api/spaces/$HALO_SPACE_ID/artifacts/file" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"parentPath":"","name":"notes.md","content":"# Notes"}'
     # body: {"parentPath":"","name":"notes.md","content":"# Notes"}
     # out: {"success":true,"data":{"path":"/…/notes.md"}}
     # err: 400 if name is missing. parentPath and content are optional — an empty parentPath creates the file at the space root, content defaults to empty. If a file already exists at that path, it is silently overwritten.

POST   /api/spaces/$HALO_SPACE_ID/artifacts/folder                 Create a new folder in a space
     curl -sX POST "$HALO_API_URL/api/spaces/$HALO_SPACE_ID/artifacts/folder" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"parentPath":"","name":"assets"}'
     # body: {"parentPath":"","name":"assets"}
     # out: {"success":true,"data":{"path":"/…/assets"}}
     # err: 400 if name is missing. parentPath is optional — omit it to create at the space root.

POST   /api/spaces/$HALO_SPACE_ID/artifacts/move                   Move a file or folder to a different directory
     # note: reversible — can be undone or corrected afterward.
     curl -sX POST "$HALO_API_URL/api/spaces/$HALO_SPACE_ID/artifacts/move" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"oldPath":"/absolute/path/inside/the/space/file.md"}'
     # body: {"oldPath":"/absolute/path/inside/the/space/file.md"}
     # out: {"success":true,"data":{"path":"/…/new-location/file.md"}}
     # err: 400 if oldPath is missing. newParentPath is optional — omit it to move to the space root.

POST   /api/spaces/$HALO_SPACE_ID/artifacts/reconcile              Resync the file list with what is actually on disk
     curl -sX POST "$HALO_API_URL/api/spaces/$HALO_SPACE_ID/artifacts/reconcile" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {"success":true}
     # note: Use after files changed on disk outside of Halo (e.g. via a terminal command) and the file list looks stale.

POST   /api/spaces/$HALO_SPACE_ID/artifacts/rename                 Rename a file or folder
     # note: reversible — can be undone or corrected afterward.
     curl -sX POST "$HALO_API_URL/api/spaces/$HALO_SPACE_ID/artifacts/rename" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"oldPath":"/absolute/path/old-name.md","newName":"new-name.md"}'
     # body: {"oldPath":"/absolute/path/old-name.md","newName":"new-name.md"}
     # out: {"success":true}
     # err: 400 if oldPath or newName is missing. Fails if a file already exists at the new name.

GET    /api/spaces/$HALO_SPACE_ID/artifacts/tree                   Get the full lazy-loadable file tree for a space
     curl -s "$HALO_API_URL/api/spaces/$HALO_SPACE_ID/artifacts/tree" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {"success":true,"data":{"workspaceRoot":"/…","nodes":[{"id":"…","name":"src","type":"folder","childrenLoaded":false}]}}
     # note: Folder nodes may have childrenLoaded:false — call POST /api/spaces/:spaceId/artifacts/children to load their contents.

POST   /api/spaces/$HALO_SPACE_ID/open                             Get a space working directory path
     curl -sX POST "$HALO_API_URL/api/spaces/$HALO_SPACE_ID/open" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {"success":true,"data":{"path":"/Users/me/HaloSpaces/work"}}
     # note: Returns the path only. It opens nothing — use this to find where a space keeps its files.

GET    /api/spaces/default-path                                    Read the directory new spaces are created under
     curl -s "$HALO_API_URL/api/spaces/default-path" -H "Authorization: Bearer $HALO_API_TOKEN"
     # out: {"success":true,"data":"/Users/me/HaloSpaces"}

PUT    /api/spaces/reorder                                         Set the display order of spaces
     # note: reversible — can be undone or corrected afterward.
     curl -sX PUT "$HALO_API_URL/api/spaces/reorder" \
          -H "Authorization: Bearer $HALO_API_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"spaceIds":["<uuid>","<uuid>","<uuid>"]}'
     # body: {"spaceIds":["<uuid>","<uuid>","<uuid>"]}
     # out: {"success":true}
     # note: Send every space id in the order you want. A partial list scrambles the rest — call GET /api/spaces first and reorder that full list.

-----------------------------------------------------------------------
$HALO_API_URL, $HALO_API_TOKEN and $HALO_SPACE_ID are already set in your Bash
  environment. Copy commands as-is; never expand or print those variables.
Replace only <angle-bracket> placeholders. Get real ids from a list call above.
Read the response body and check "success". HTTP 200 alone does not mean it
  worked - many failures return 200 with {"success":false}.
Pipe long responses through `| head -c 4000` so you do not flood your context.
A POST that timed out may still have taken effect. List before you retry.
Waiting on something? Back off (2s, then double), give up after 5 tries and
  tell the user it is still running.
Large or binary files do not go through this API - use Read / Write / Bash.
403 = the endpoint exists but is closed to me in this build. Tell the user to
  do it in the Halo app. Do not tell them Halo cannot do it.
404 with a "code" field = my path is wrong. 404 without one = the id is wrong.
Only call paths listed on this page or in the index. Never write one from
  memory. If this page has left your context, call halo_api_ref again.
Full index of every endpoint: {{API_REF_INDEX_PATH}}/index.txt
  grep -i "<keyword>" {{API_REF_INDEX_PATH}}/index.txt
Not listed here does NOT mean not supported — that is a real, deliverable
  answer, not a failed search. Grep the index before you say "Halo can't do that".
