Halo 是一款開源的桌面 AI 工作站。日常用法和主流桌面 AI 工作台一樣：對話、寫程式碼、做文件、查資料。更進一步，你可以擁有長期在崗的**數位人**，讓它們組成團隊分工協作；人不在電腦前時，也能透過手機、飛書、微信或企業微信隨時交辦和追蹤。

## 為什麼是 Halo

人人都在用 AI，每個人自己的效率確實提升了；可工作之間的銜接還是靠人：把這個 AI 的結論複製給那個 AI，把檔案和結論轉給同事，同事再對自己的 AI 重講一遍。人成了最大的瓶頸：個人提效了，團隊的效率卻沒有跟上來。

Halo 讓 AI 之間直接分工、交接、累積記憶、持續值守，人只負責定方向、做決定。個人提效是加法，協作提效是乘法。

- **適合誰**：重度 AI 使用者、開發者、研究與營運人員，以及想把 AI 用進日常流程的小團隊。
- **三件事**：[日常 AI 工作台](#一日常-ai-工作台) · [數位人與數位人團隊](#二數位人與數位人團隊) · [隨時隨地交辦](#三隨時隨地交辦)
- **由 Halo 寫成**：AI 自我迭代的大型 AI 工作站，超過 50 萬行程式碼，穩定運行於金融企業級環境。

## 一、日常 AI 工作台

- **對話 + 畫布**：報告、程式碼、網頁、終端機、Word / Excel / PDF 都能在對話旁邊開啟；選取一段內容、加一句註解，AI 就知道你說的是哪裡。
- **按需開啟能力**：輸入框的「＋」裡一鍵開啟網頁控制、團隊協作、AI 終端機、文字辨識、操作 Halo；本機檔案和資料夾直接附加，不用上傳。
- **寫程式碼**：可選 Claude Code、Codex、Halo SDK 等引擎；在變更檢視裡看清 AI 實際改了什麼，再一鍵發起快速審查，或多角色的團隊審查。
- **AI 瀏覽器與終端機**：AI 操作真實的瀏覽器和終端機，你在旁邊看得見，隨時接手或停止。
- **辦公文件**：內建文件處理技能和執行環境，直接產生、修改 Word、Excel、PPT、PDF，不用先裝一堆相依套件。
- **知識庫與記憶**：檔案、資料夾、PDF、Office 文件匯入知識庫後，聊天時自動引用並標註出處；同一空間的多個聊天共享記憶，按「目前狀態 / 歷史 / 專題知識」分層整理，換個聊天不用從頭介紹。
- **對話互通、操作 Halo**：新開一個對話問「其他幾個對話進行得怎麼樣了？」，它會逐一查看、彙整給你；AI 也能替你管理空間、數位人和設定。
- **接入你的工具**：MCP 服務和技能（Skills）一鍵連接，相容 Claude Code 的 MCP 與 Skills 生態系。
- **多模型、多帳號**：支援任意 Anthropic / OpenAI 相容的 API，也能同時登入多個 ChatGPT、Claude、GitHub Copilot 帳號，按對話切換模型與思考強度。

## 二、數位人與數位人團隊

一個 AI 包辦所有事，注意力有限；只認識你的 AI，幫不上整個團隊。分工不只適用於人，也適用於 AI。

| | 一個 AI 包辦 | 數位人團隊 |
|---|---|---|
| 分工 | 說明和工具擠在一處 | 每個數位人只管一道工序 |
| 出了錯 | 不知道哪一步錯了 | 哪道工序出錯，一眼可查 |
| 交接 | 人來轉發，重講前因後果 | 數位人之間直接提問、交付 |
| 能找誰 | 只認識你 | 還認識同事的數位人 |

- **數位人**：長期在崗的 AI 成員。按排程或事件自動執行（可以只在中國大陸工作日執行，節假日和調休補班都算在內），也能在聊天裡隨口交代一個提醒；從商店一鍵安裝，或用一句話建立。
- **一句話組隊**：在任意空間對 AI 說「幫我組個團隊，調研這三款產品」，研究、核對、寫作各有分工；想以後繼續用，再說一句「保留這個團隊」，還能為整支團隊設定執行排程。
- **跨電腦組隊**：同事帶著自己的數位人加入你的團隊，各自在自己的電腦上執行。資料留在各自電腦上，只有發布給團隊的成果在團隊裡流轉；每個數位人能做什麼，由它的主人決定。同一區域網路開啟遠端存取即可邀請，跨網路則在設定裡設定中繼閘道。
- **過程看得見**：團隊工作台集中展示任務、進度、隊友之間的對接和成果。數位人之間自己對接，團隊決定不了的事才來問你。

> 試試這樣說：「幫我研究這幾款產品，分開查資料、核對結論，最後整理成一份報告。」

### 商店、Browser Action 與生態系

- **數位人商店**：挑一個，填幾項設定就開始執行，不用寫提示詞。企業可以部署私有商店，在設定裡新增即可。
- **Browser Action：AI 決策，腳本執行**：把某個平台上的一個具體操作寫成可重複使用的 `.js` 腳本，AI 只決定做什麼、什麼時候做，腳本負責精準執行。小紅書、B 站、知乎、X 等平台已有現成的 Action，內部系統也可以撰寫私有 Action。[動手做一個 →](https://hello-halo.cc/docs/developers/digital-humans/build.html)
- **發布你的數位人**：寫一份 `spec.yaml`，向[數位人協議（DHP）](https://github.com/openkursar/digital-human-protocol)提交 PR，合併後所有 Halo 使用者都能安裝。

## 三、隨時隨地交辦

人不在電腦前，工作照樣推進。

- **手機與遠端網頁**：遠端存取執行在家裡或辦公室電腦上的 Halo，交辦任務、上傳資料、下載成果。
- **IM 接入**：支援飛書、微信、企業微信。在熟悉的聊天視窗裡向數位人交辦工作，背後可以是一整支團隊。
- **在 IM 裡做決定**：結果直接送到聊天裡；需要你拍板的事，回一句，工作就繼續往前走。

## 典型場景

| 場景 | 怎麼做 | 結果 |
|---|---|---|
| 競品 / 產業調研 | 一句話組隊：研究、核對、寫作分工 | 在團隊工作台看進度，拿到成稿報告 |
| 每日資訊簡報 | 數位人按工作日定時整理產業或研發動態 | 每天上班前推送到飛書 / 企業微信 |
| 出門在外交辦 | 在手機微信裡說「把這份方案改一下」 | 回到電腦開啟成品，或在手機上直接下載 |
| 寫程式碼 | AI 修改後在變更檢視審查，再發起團隊審查 | 看清改了什麼，放心提交 |
| 辦公文件 | 讓 AI 產生週報、表格、簡報 | 直接得到 Word / Excel / PPT 檔案 |
| 內部系統巡檢 | 數位人定時登入 OA、簽核、工單系統巡查 | 逾期和異常推送到 IM，等你處理 |
| 社群平台營運 | 安裝商店裡現成的 Browser Action 數位人 | 定時回覆留言、發布內容、追蹤輿情 |

## 快速開始

1. [下載安裝](#下載安裝)，開啟 Halo。
2. 用 Claude 或 ChatGPT 帳號登入，或者填入任意 Anthropic / OpenAI 相容服務的 API Key。
3. 建立一個空間：一個專案一個空間，檔案和記憶互不干擾。
4. 直接對話交辦；或者從商店安裝數位人、一句話組建團隊。
5. 需要時開啟遠端存取，或綁定飛書 / 微信 / 企業微信，隨時隨地繼續。

## 下載安裝

| 平台 | 下載 | 系統需求 |
|---|---|---|
| macOS（Apple 晶片） | [.dmg](https://github.com/openkursar/hello-halo/releases/latest) | macOS 12+ |
| macOS（Intel） | [.dmg](https://github.com/openkursar/hello-halo/releases/latest) | macOS 12+ |
| Windows | [.exe](https://github.com/openkursar/hello-halo/releases/latest) | Windows 10+（x64） |
| Linux | [.AppImage](https://github.com/openkursar/hello-halo/releases/latest) | glibc 2.34+（Ubuntu 22.04+、Debian 12+） |
| Android（遠端客戶端） | [.apk](https://github.com/openkursar/hello-halo/releases/latest) | Android 7.0+ |
| iOS（遠端客戶端） | 從原始碼建構 | iOS 15+ |

下載、安裝、執行，不需要 Node.js、npm 或命令列；沒有伺服端依賴，IT 可以直接派送。之後自動更新：Windows 從 3.0 起，新版本會在背景準備好，點重新啟動即可完成。Linux 版暫不包含 AI 終端機。

### 從原始碼建構

```bash
git clone https://github.com/openkursar/hello-halo.git
cd hello-halo
npm install
npm run prepare
npm run dev
```

## 技術特點

- **開源，執行在你自己的電腦上**：檔案與工作環境由你掌控；Halo 沒有自己的後端服務。
- **可插拔 Agent 引擎**：Claude Code、Codex，以及自行研發的 Halo SDK（資源佔用低、啟動更快，針對開源模型最佳化）、DeepSeek dsh，按需選擇。
- **去中心化的分散式數位人團隊**：成員分散在不同電腦上協作，沒有中央伺服器；團隊狀態借鑑 Raft 共識演算法，按多數派選出負責節點、按任期複製日誌，負責節點所在的電腦離線後自動重新選舉，不會出現兩個負責節點，團隊照常運作。[設計說明](https://hello-halo.cc/docs/advanced/team-consensus.html)（簡體中文）
- **細節**：空間隔離、深淺色主題、50%–150% 介面縮放，介面支援 7 種語言。

## Halo 的故事

2025 年 10 月，一個簡單的困擾：**我想用 Claude Code，但整天在開會。**

在一個無聊的會議上，我想：*如果能用手機遙控家裡電腦上的 Claude Code 呢？*

然後是第二個問題——非技術同事也想用，但卡在了安裝上。*「npm 是什麼？」*

於是我做了 Halo：視覺化介面、一鍵安裝、遠端存取。第一個版本花了幾個小時。之後的一切？**幾乎全部由 Halo 自己建構。** 2026 年初，Halo 開源。

我們相信下一步是 **AI 工作站**：AI 不再需要有人盯著才能做事。你設定目標，數位人 7x24 自主推進，你只在關鍵節點做決策。3.0 讓數位人組成團隊、跨電腦協作，離這個目標又近了一步。

—— [@openkursar-flynn](https://github.com/openkursar-flynn)，Halo 發起人
